# Prior art

Steal the rule, not the whole product.

**CareerForge** ([MasRama/careerforge](https://github.com/MasRama/careerforge)). Closest locker: evidence in, claims out, refuse a claim the records will not carry, local, no account. Collectors are git and coding sessions. Glen’s sellable work is mostly not git. Steal the provenance rule.

**vibe-resume** ([easyvibecoding/vibe-resume](https://github.com/easyvibecoding/vibe-resume)). Extractors for Cursor transcripts and ChatGPT exports, then a résumé. Coding-career bias. Optional later adapter, not the product.

**Recallr** ([Flowdesktech/recallr](https://github.com/flowdesktech/recallr), MIT). mbox and Slack zip into SQLite hybrid search, plus MCP. Candidate search backend. Not claim cards.

**LEANN** ([yichuan-w/LEANN](https://github.com/yichuan-w/LEANN)). Laptop RAG over files, mail, and ChatGPT exports. Retrieval, not a buffet.

**RenderCV / JSON Resume.** PDF later. Do not build a CV renderer in v0.

**data_dumps** (house). ZIP → DuckDB → Marimo. LinkedIn, Slack, and ChatGPT message text are already loaded. Read that warehouse. Do not grow a second processor.

**Rollup** (house). Parses Thunderbird mbox bodies for a newsletter digest. Wrap `parse.py` when a mail adapter is real. data_dumps Thunderbird tables do not store bodies.

**Paperful** (house). `llm/client.py` is the Ollama default plus optional LiteLLM, with an egress notice. Copy that client shape. Paperful itself fills Zotero PDFs.

**zotero-rag** (house, [anapaulagomes/zotero-rag](https://github.com/anapaulagomes/zotero-rag)). Hoops and Ocean already run as two instances. Own pubs is a third instance, not a new embedder. See `zotero-rag-pubs.md`.
